# Monopoly-Game

This repository contains **Property Empire 3D**, an original Monopoly-inspired 3D board game for desktop and mobile browsers with offline bots and LAN multiplayer.

The project lives in [`PropertyEmpire3D/`](PropertyEmpire3D/). Start with its [README](PropertyEmpire3D/README.md):

```bash
cd PropertyEmpire3D
npm install
npm run build
npm run start:lan   # then open the printed address
```
